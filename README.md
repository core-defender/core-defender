# Core Defender

Minecraft 1.21.1 · NeoForge 기반의 디펜스 모드팩입니다. 서버가 공유하는 디펜스 차원에서 성벽과 포탑으로 몰려오는 몬스터를 막고, 탐험과 공학으로 방어 수단을 확장합니다.

Create → Immersive Engineering → IE Petroleum → Mekanism으로 이어지는 공학 성장과 전투 파밍의 연결을 목표로 합니다. Java 동반 모드와 KubeJS로 장벽·포탑·자동 웨이브·보급 시스템을 구현합니다.

개발·운영·설계 문서는 `docs/` 폴더에 정리되어 있습니다. 문서별 안내는 [AGENTS.md](AGENTS.md)를 참고하세요.
