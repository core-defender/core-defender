# 웨이브

자동 웨이브 진행, 스폰, 보스, 몹 AI와 설정 파일을 정리한다. 관련 명령은 [명령어](commands.md)를 참조한다.

## 진행 규칙

- 최초 `/cd start`로 자동 진행을 활성화한다. 첫 전투와 클리어 후 대기는 기본 10분이며 시작 1분 전 전체 플레이어에게 알린다. 빠른 시작 보상 배율은 폐지했으며 현재 배율은 1이다.
- 1-1~1-10, 2-1~2-10의 두 난이도를 구현했다. 10웨이브 이후 일반 적 구성은 고정하고 반복 5회마다 미니 보스, 10회마다 보스를 추가한다.
- 1-10 클리어 후 성벽이 온전하고 전투 중이 아닐 때 기지에서 명령 또는 메뉴로 2단계에 진입한다. 2단계 이후 승급은 없다.
- 스폰은 네 성벽 면의 길이에 균등하게 배정한 위치에서 수직 바깥쪽으로 떨어진 곳이다. 원형 띠와 고정 스폰 지점은 사용하지 않는다. 기본 거리는 성벽 크기에 따라 64~128블록이며 지형과 위치 유효성의 영향을 받는다.
- 일반 적은 1단계 120~480마리, 2단계 560~1,000마리이며 소규모 배치로 계속 유입된다. 기본 동시 생존 상한은 최대 256마리다.
- 5웨이브는 강화 변명자, 1-10은 소환사, 2-10은 강화 피글린 야수다. 보스는 일반 적 소환 완료 후 생존 일반 적 비율이 20% 이하일 때 등장한다.
- 소환사만 90%에서 60초 동안 소진되는 피해 감소 방호를 받는다. 우민·파괴수를 추가 소환하며 보스와 남은 소환수를 모두 처치해야 클리어한다.
- 패배하면 남은 적을 제거하고 번호를 유지하며 보상을 지급하지 않는다. 붕괴 알림 뒤 수복 안내를 출력한다. 붕괴 구간을 모두 복구한 후 새 준비 시간을 부여하며 확장 크기는 유지한다.
- 전원 로그아웃 시 준비 타이머를 정지한다. 다른 차원에 접속 중이어도 진행되며, 진행 중 서버 재시작 시 해당 전투를 정리하고 재도전을 준비한다.
- 관리자는 자동 시작 중지·재개와 즉시 시작을 별도로 제어한다. 설정 JSON은 검증 후 재적용하며 진행 중 전투에는 시작 시점 설정을 유지한다.

## 현재 구현

웨이브는 난이도별 10단계이며 이번 구현은 1-1부터 2-10까지다.

- 최초 `/cd start`로 자동 진행을 켠다. 첫 웨이브와 매 클리어 이후 대기는 10분이며, 시작 1분 전 접속 중인 모든 플레이어에게 채팅·화면 알림을 보낸다. 반복 명령은 타이머를 초기화하지 않는다.
- 전원 로그아웃 시 준비 타이머는 정지한다. 탐험 중 다른 차원에 있어도 자동 시작한다. 진행 중 전투 자체는 서버가 실행되는 동안 계속된다.
- 성벽 붕괴 시 같은 웨이브를 재도전한다. 복구 전에는 준비 타이머가 멈추며 복구 후 10분의 준비 시간을 준다. 진행 중 서버 재시작 시 전투를 정리하고 10분 뒤 재도전한다.
- 10웨이브 클리어 후 일반 적의 수량·능력치는 고정된다. 반복 5회마다 미니 보스, 10회마다 일반 보스가 나온다.
- 기지에서 `/cd difficulty up` 또는 메뉴의 ‘난이도 상승’을 두 번 눌러 1단계에서 2단계로 승급한다. 2단계 이후 승급은 잠겨 있다.
- 1단계 일반 적은 120→480마리, 체력 1→1.8배, 공격력 1.2→2배. 2단계는 560→1,000마리, 체력 2→3배, 공격력 2.2→3.5배다. 정예는 별도 배율을 추가 적용한다.
- 한 번에 4→8 / 8→12마리를 둘레에 분산 소환하고 웨이브 후반으로 갈수록 유입 간격을 30% 줄인다. 동시 생존 상한은 96→192 / 192→256마리다. 소환 위치 실패 시 해당 적은 다음 소환 주기에
  재시도한다.
- 5웨이브는 강화 변명자, 1-10은 소환사, 2-10은 좀비화하지 않는 강화 피글린 야수다. 보스는 일반 적 소환이 끝나고 생존 일반 적이 전체의 20% 이하일 때 등장한다.
- 소환사만 초기 피해 감소율 90%를 받으며 60초에 걸쳐 0%까지 약해진다. 남은 방호율은 체력바·파티클로 표시한다. 기본 갑옷은 별도 적용한다.
- 소환사는 등장 10초 후부터 15초마다 우민 부대 3마리를 소환한다. 변명자 2마리와 약탈자/파괴수를 번갈아 소환하고, 소환수 생존 상한은 12마리이며 전체 동시 생존 상한에도 포함한다. 보스 처치 후 추가
  소환은 멈추지만 남은 소환수까지 처치해야 클리어한다.
- 일반 몹끼리의 오사격·폭발 피해 방지와 포탑 넉백 방지는 유지한다. 적 투사체는 발사 시 적 소속과 피해 배율을 저장하므로 발사자가 죽어 제거되어도 장벽 충돌·아군 피해 방지가 유지된다.

기존 수동 웨이브 세이브는 진행도를 최대 10까지 보존하고 자동 진행은 명령으로 활성화한다. 새 밸런스를 처음부터 테스트하려면 `/cd admin reset progress`를 사용한다. 숫자는 실전 플레이 전
조정값이며 256마리 동시 전투의 모드팩 성능은 추가 확인이 필요하다.

## 스폰 위치

웨이브 스폰 거리는 스테이지가 아니라 성벽 크기에 연동한다. 성벽이 2×2 / 4×4 / 6×6 / 8×8청크일 때 외곽에서 각각 64 / 85 / 107 / 128블록 떨어진 둘레에 무작위로 소환한다. 모서리
집중을 막기 위해 네 면의 길이에 균등하게 지점을 배정한 뒤 각 면의 수직 바깥쪽에 소환하며, 블록 중심으로 배치할 때 약 0.71블록 이내 오차가 생길 수 있다. 청크 로딩과 경로 탐색도 이 둘레에 8블록 여유를
더해 확보한다.

## 몹 AI

- 기본 타겟: 가장 가까운 성벽 구간.
- 이동: **플로우 필드** — 성벽에서 바깥으로 거리 지도를 한 번 계산, 몹은 거리가 줄어드는 방향으로 이동.
- 장벽으로 직접 접근 가능한 평지에서는 직선 접근을 사용하며, 장애물이 있으면 경로 지도를 사용한다. 목표에 분산 오프셋을 반복 적용해 모서리로 미는 처리는 없다.
  장애물 설치/파괴 시에만 재계산. 장애물 칸은 "지나갈 수 있지만 비용이 큰 칸"으로 두어, 길이 막히면 자연스럽게 장애물을 공격.
- 플레이어 어그로: 플레이어가 몹을 공격하면 반경 12블록 안의 몹 중 **플레이어에게 도달 가능한 몹만** 10초 동안 플레이어를 노린다. 추적 최대 거리는 24블록이다.
  시간 초과·거리 이탈 시 성벽으로 복귀. 플레이어만 바라보지 않도록 한다.
    - 근접 몹: 플레이어에게 걸어서 닿을 수 없으면 (예: 장벽 안쪽, 사격대 위) 계속 성벽을 노린다.
    - 원거리 몹: 사거리 + 시야가 닿으면 반격 → 장벽 안쪽이나 사격대도 완전한 안전지대가 아니다.
- 웨이브 몹끼리는 피해 없음, 투사체는 웨이브 몹을 통과.

### 성벽 피해

일반 몹의 성벽 피해에는 월드 난이도를 적용한다. 기본 피해를 D라 할 때 평화로움 0, 쉬움 `min(D/2+1, D)`, 보통 D, 어려움 `1.5D`이며 정수 반올림한다.
근접은 몹의 공격력 속성 (없으면 2), 화살은 기본 3에 웨이브 피해 배율을 적용한다. 관리자 `wall damage`는 난이도 보정 없이 지정 HP를 차감한다.
붕괴 시 `[디펜스]` 붕괴 알림을 먼저 출력하고 진행 중인 웨이브가 있으면 실패·수복 안내가 뒤따른다.

## 설정 파일

게임 실행 중 웨이브 설정 변경:

1. 인스턴스의 `kubejs/config/coredefender-waves.json`을 수정한다. 저장소에서는 같은 상대 경로다. 새 설치에 파일이 없으면 JAR에 포함된 기본값으로 한 번 생성한다. 기존 파일은
   덮어쓰지 않는다.
2. 관리자 명령 `/cd admin config reload`로 검증 후 적용한다. JSON 문법 오류, 없는 몬스터·보상 아이템, 잘못된 수치 등은 거부하고 기존 설정을 유지한다.
3. 진행 중인 웨이브의 몹·보상·소환 거리·보스 방호·소환 규칙은 시작 시점의 값을 유지한다. 현재 대기 타이머도 유지한다. 다음 웨이브부터 새 설정을 사용한다.
4. 대기 중인 타이머에도 새 간격을 적용하려면 `/cd admin config timer`를 실행한다. 진행 중인 전투에서는 거부하며, 새 간격은 최소 60초라 경보를 생략하지 않는다.

주요 항목:

| JSON 항목                                                 | 의미 / 단위                                                        |
|-----------------------------------------------------------|--------------------------------------------------------------------|
| `waveDelaySeconds`                                        | 준비 시간, 초 (기본 600)                                           |
| `tiers[0][0]` ~ `tiers[1][9]`                             | 1-1 ~ 2-10의 구성                                                  |
| `mobs`, `rewards`                                         | 엔티티/아이템 ID와 수량                                            |
| `healthMultiplier`, `damageMultiplier`, `speedMultiplier` | 일반 적 능력치 배율                                                |
| `maxAlive`, `spawnBatchSize`, `spawnInterval`             | 동시 생존 상한, 회당 소환 수, 소환 간격(틱, 20틱=1초)              |
| `bosses[0/1].mini/repeatMini/boss`                        | 각 단계의 미니 보스/반복 미니 보스/일반 보스 종류·체력·공격력·갑옷 |
| `rules.spawnMinDistance/spawnMaxDistance`                 | 최소/최대 성벽 크기의 외곽 소환 거리, 블록                         |
| `rules.spawnAcceleration`                                 | 후반 소환 간격 단축 비율 (기본 0.3)                                |
| `rules.bossRemainingFraction`                             | 보스 등장 시 허용하는 남은 일반 적 비율 (기본 0.2)                 |
| `rules.wardReduction/wardSeconds`                         | 소환사 초기 피해 감소율/해제 시간, 비율·초                         |
| `rules.summonInitialSeconds/summonIntervalSeconds`        | 소환사 첫 소환 대기/이후 주기, 초                                  |
| `rules.summonMaxAlive/summonBatchSize`                    | 소환수 생존 상한/회당 수량                                         |
| `rules.summonerStandOff`                                  | 소환사가 성벽에서 멈추는 거리, 블록                                |

구조는 2개 난이도 × 10개 웨이브로 고정한다. 소환사 행동·시간제 방호는 보스 엔티티를 `minecraft:evoker`로 지정했을 때 적용한다. 이 설정 기능을 처음 도입할 때는 새 JAR 설치와 재시작이 한
번 필요하며, 이후 수치 변경에는 재시작이나 `/reload`가 필요 없다. 포탑 능력치 등 이 파일에 없는 Java 설정은 별도다.
