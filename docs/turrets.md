# 포탑

현재 구현 기준(0.1.5 계열)과 설계 방향을 정리한다. 관련 명령은 [명령어](commands.md), 공학 단계별 방어 수단 계획은 [설계](design.md#공학-단계-초안)를 참조한다.

## 설계 방향

- 초반 제작 포탑은 화살·투석·기름 3종이다. 화염 포탑은 등록과 기능을 유지하되 제작법은 제외했다.
- 포탑별 탄약·연료를 소비하며 기본 모듈 슬롯은 2개다. 제작 가능한 모듈은 10종 × I~III이며 중복 장착 효과를 합산한다.
- 상세 UI, 면별 자동화, 재고 상한, 분석기 범위 표시와 회수 시 자원·설정 보존을 지원한다.
- 기름은 성벽 안쪽에서 외곽 바닥에 쏟는다. 감지는 전방 부채꼴이며 실제 흐름은 부채꼴 제한 없이 낙차를 우선한다. 평지 기본 이동은 5칸이고 낙하 후 이동 거리를 다시 계산한다.
- 기본 수치와 제작법은 아래 현재 구현과 코드를 기준으로 한다. 포탑 자체 레벨은 없으며 다음 티어 업그레이드는 향후 설계다.
- 처치 주체(포탑/플레이어)에 따른 드롭 분리는 향후 설계다.

## 구현 기준

화살/투석/기름 및 보존된 화염 포탑과 2슬롯 모듈, 면별 자동화, 자원 보존 회수, 상세 UI 및 분석기 표시를 구현했다.
기존 문서의 단일 기초 포탑 수치보다 `turret/TurretStats.java`와 이 문서를 우선한다.
투석 사거리 모듈의 탄도 도달 보정과 II/III 제작법 및 난이도별 10단계 웨이브 구성을 구현했다.
현재 수치·제작법·조정 파일은 이 문서와 실제 코드·설정을 기준으로 확인한다.
모든 포탑 피해 (물약 화살의 지연 효과 포함)는 넉백을 발생시키지 않는다.

## 현재 구현

모듈·증폭을 적용하기 전 기본값이다. 실제 피해는 대상 방어와 탄도·접촉 여부에 따라 달라진다.

| 포탑        | 직접 피해                 | 기본 공격 주기 | 사거리 / 범위             | 기본 소비               |
|-------------|---------------------------|----------------|---------------------------|-------------------------|
| 화살        | 5                         | 16틱(0.8초)    | 24칸                      | 실제 발사한 화살 수만큼 |
| 투석 일반   | 9                         | 60틱(3초)      | 36칸 / 폭발 반경 3칸      | 돌과 연료               |
| 투석 심층암 | 13                        | 60틱(3초)      | 32칸 / 폭발 반경 4칸      | 심층암과 연료           |
| 화염        | 타격당 3, 분사 중 4회     | 30틱(1.5초)    | 5칸 / 전방 90°            | 분사 10틱 × 종자유 4mB  |
| 기름        | 접촉 타격당 3, 주기당 4회 | 30틱(1.5초)    | 평지 이동 5칸 / 감지 10칸 | 투하당 종자유 40mB      |

화살 다중발사는 적이 한 마리여도 같은 적을 중복 조준하며 실제 발사 수만큼 소비한다. 도탄은 마지막 관통 타격이 명중해야 발생한다.
웨이브 적의 피해 무적 시간을 제거하여 여러 포탑이 동시에 명중해도 각 피해를 적용한다.

화살/투석/기름과 보존된 화염 포탑, 2개 모듈 슬롯, 제작 가능한 10종 × I~III 모듈, 증폭 자원,
실제 탄도/관통/다중발사/도탄/집속탄/부채꼴 분사/포탑별 잔류 화상을 구현했다.

공통 사거리 모듈 `module_range_1`~`module_range_3`은 투석·화염·기름 포탑에 장착한다. 등급당 투석 사거리 +15%, 화염 사거리 +0.5블록·방사각 +45°이며 두 슬롯은 합산한다. 구형
`module_stone_range_*` / `module_flame_range_*`도 같은 효과로 작동하고, 제작창에서 같은 등급의 공통 사거리 모듈로 교환한다.

초반 제작 포탑은 화살/투석/기름이다. `flame_turret`의 등록·기능·기존 설치물은 유지하며 제작법만 제외한다. 기름 포탑은 `/give @s coredefender:oil_turret` 또는
철·양동이·원목·화로·조약돌 제작법으로 얻는다.

- 기름 포탑은 성벽 바로 안쪽 끝 칸에 설치하며 설치자가 바라보는 수평 방향으로 고정된다. 바깥 방향이어야 외곽 바닥에 쏟는다. 방향은 저장되며 회수 후 재설치할 때 다시 정한다.
- 성벽 외곽면 기준 전방 90°·10칸에서 적을 감지해 선제 투하한다. 감지 거리는 모듈 적용 후 공격 범위의 2배다. 기본 1.5초마다 종자유 40mB를 소비하고 자동 점화한다. 기름 탱크는 9000mB이며 용암
  탱크 1000mB를 지원한다. 증폭 시 1회 10mB를 함께 소비하며 피해·화상 +30%를 적용한다. 용암이 10mB 미만이면 기본 공격으로 전환하거나 설정에 따라 정지한다.
- 기름은 0.5초마다 용암처럼 가까운 낙차로 이어지는 방향을 우선해 흐른다. 낙차가 없으면 사방으로 퍼지며 평지 이동은 기본 5칸 (사거리 모듈 적용 후 소수점 버림)이다. 아래로 떨어지면 평지 이동 거리를 다시
  계산하며 부채꼴 제한은 없다. 오르막·막힌 통로·유체가 있는 칸·성벽 내부로는 흐르지 않는다. 각 낙하 탐색은 최대 8블록이며 미로딩 청크는 로드하지 않는다. 실제 용암의 유체 높이·원천 블록 생성은 구현하지
  않으며 6초 수명과 96칸 상한을 유지한다.
- 투하 시점부터 6초간 잔류하며 접촉한 적에게 화염 포탑과 같은 주기로 0.5초간 3 피해를 4회 주며, 1.5초 주기로 반복한다. 마지막 명중 후 4초간 초당 1의 잔류 화상도 적용한다. 같은 포탑의 겹치는 칸은
  중복 피해가 없고 다른 포탑의 피해는 독립 적용한다. 아군·플레이어·블록 피해 및 넉백은 없다.
- 공격력·공격속도·공통 사거리·잔류 화상 모듈을 지원한다. 사거리 등급당 평지 이동 예산 +0.5칸 (합산 후 소수점 버림), 감지각 +45° (최대 360°), 감지 거리 +1칸이다. 감지각은 실제 기름 확산
  방향을 제한하지 않는다. 공격력은 직접 피해·화상에, 잔류 화상 모듈은 화상에
  적용한다. 공격속도는 0.5초 공격 구간 뒤의 휴지기를 줄인다.
- 기울어지는 솥과 낙하·불꽃·연기 파티클로 표현하며 실제 유체·불 블록을 생성하지 않는다. 기름이 깔린 각 블록에는 지면 높이를 따라 어두운 바닥색과 주황색 사각 테두리를 표시한다. 포탑 간 중복 칸은 한 번만
  그리며, 최대 96칸의 위치·높이·남은 시간을 5틱마다 한 패킷으로 해당 포탑 청크를 추적하는 플레이어에게 보낸다. 잔류 기름은 임시 효과여서 포탑 파괴·청크 재로딩 시 사라진다.
- 방어 분석기의 주황색은 감지 부채꼴, 청록색 원은 평지 흐름 거리의 참고 표시다. 실제 기름 영역은 지형에 따라 달라지고 낙하 후에는 더 멀리 흐를 수 있다. 자동화 면 설정·종자유 재고 상한·빈 용기 출력은
  다른 포탑과 동일하다.

`basic_turret` ID는 화살 포탑으로 유지하고 기존 9칸 탄약을 보존한다.

- 포탑 우클릭: 자원 인벤토리와 운용/모듈/설정 UI. 웅크려 우클릭: 빠른 자원 투입.
- 방어 분석기로 우클릭: 15초간 해당 포탑 사거리 표시. 여러 포탑을 각각 표시할 수 있다.
- 모든 자동화 면은 기본 차단. 설정에서 아래/위/북/남/서/동의 입력/출력/입출력을 지정한다.
- 자동화 입력 상한은 탄약 전체/연료/증폭 아이템/종자유/용암별로 설정한다. 모듈 자동 삽입은 지원하지 않는다.
- 자동 출력은 빈 용기이며 탄약·연료·모듈·저장 유체는 추출되지 않는다. UI의 수동 유체 회수 결과는 직접 꺼낸다.
- 화살 탄약 9칸, 투석 돌 8칸+연료 1칸, 화염·기름 종자유 9000mB+용기 투입/회수. 증폭 아이템 1칸 또는 유체 1000mB.
- 파괴 회수 시 자원·모듈·설정·남은 연료/증폭 횟수·장전 시각을 포탑 아이템에 저장한다.
- 포탑은 디펜스 차원 성벽 내부에서만 공격하며 웨이브/관리자 테스트 적/Dummy만 타격한다.
- 화살/물약 효과/투석/파편/화염/잔류 화상은 넉백 없이 피해를 준다. 기존 몹끼리 피해 방지 규칙은 유지한다.
- 빨강 상태등은 필수 자원 부족, 금색은 증폭 소진 또는 용기 출력 막힘, 회색은 레드스톤 정지다. 바라보면 사유가 표시된다.
- 실제 DPS는 최근 10초의 실제 HP 감소량 합계/10이다. 장갑 경감과 초과 피해를 반영하며 화상/파편/물약 효과를 원래 포탑에 귀속한다.

## 종자유 (Vinery 수동 압착)

Vinery 1.5.6의 `vinery:grapevine_pot`에 씨앗 제작 경로를 추가한다. 기존 포도 제작은 유지한다.
빈 통에 `c:seeds`의 같은 씨앗을 10개 넣고 플레이어가 12번 착지하면 일반 유리병으로
`coredefender:seed_oil_bottle` 1개 (250mB)를 회수한다. 우클릭은 1개, 웅크려 우클릭은 남은 공간까지 투입한다.
씨앗당 25mB로 Create Crafts & Additions 기본 압착 (씨앗당 100mB)의 1/4 수율이다.
압착 전 통을 파괴하면 씨앗이 반환되고, 압착을 시작한 내용물은 파괴 시 소실된다.
제작 진행도는 저장·동기화되며, 몹 착지는 압착으로 인정하지 않는다.
진행 상황은 텍스트 없이 통 내용물 렌더링(씨앗 더미 → 반죽 → 기름 표면)과 소리로만 보여 주고, 제작법은 JEI `종자유 압착` 항목으로 안내한다. 다른 씨앗을 넣으면 실패음만 난다.
Create 주입/추출 레시피는 병당 250mB이며, 종자유 병 4개와 빈 양동이로 1,000mB 양동이를 제작할 수 있다.
제작 재료로 사용한 종자유 병은 빈 유리병을 반환한다. 새 아이템 등록을 위해 게임 재시작이 필요하다.

## 조정 위치

조정 위치:

- 기본 피해/주기/사거리/모듈 합산: `mod/src/main/java/lkd/namsic/coredefender/turret/TurretStats.java`
- 분사 소모량/자원량/슬롯/기본 설정: `turret/BasicTurretBlockEntity.java`
- 제작법: `kubejs/server_scripts/coredefender/turrets.js`, `recipes.js`
- 웨이브/보상/수복 비용: `kubejs/config/coredefender-waves.json`
- 일반 돌/심층암 허용: `mod/src/main/resources/data/coredefender/tags/item/turret_stones.json`, `turret_deepslate.json`

투석 사거리 모듈은 물리적으로 늘어난 사거리에 도달하도록 발사 속도에도 `sqrt(1+사거리 보너스)`를 적용한다.
화약의 탄속 +15%는 별도 적용된다. II는 하위 모듈+Create 정밀 기계장치+황동 2개,
III는 하위 모듈+IE 전자 부품+강철 2개로 초기 제작법을 잡았다. 둘 다 추후 밸런스 조정 대상이다.
화염은 기본 10틱 분사+20틱 휴지기이며 공속 모듈은 휴지기만 줄인다.
